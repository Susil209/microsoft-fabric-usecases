## Issues faced

- Ambiguous column reference for `type` during join/select in PySpark
- Fixed by explicitly using aliases:
  - `store_type`
  - `holiday_type`

- DATATYPE_MISMATCH error regarding date_add. I'm trying to add BIGINT (from a Range or id column) to a date. Spark's date_add    function requires an Integer. 
- Fixed by using sequence() and explode().
    - sequence(start, end, interval 1 day) creates an array of dates from min_date to max_date.
    - explode turns that array into one row per date.
